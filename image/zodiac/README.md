# 星座眼睛 C1 图片素材

已制作天蝎座、双鱼座、巨蟹座三套图片，每套 8 张，共 24 张。各目录的 `eye_master.png` 保存最初的主眼原图，后续 7 张均独立引用本目录主眼，用内置 image_gen 编辑生成。打开 `preview.html` 可集中查看。

`prompt.txt` 保存主眼提示词；`emotion_prompts.json` 保存情绪与眨眼提示词；如存在 `eye_angry_final_prompt.txt`，以该文件作为怒表情最终提示词（修正右眼内低外高的眼睑方向）。

|---|---|
| eye_master.png | 普通 / 中性 |
| eye_happy.png | 喜：温和开心 |
| eye_angry.png | 怒：内侧压低 |

| eye_joy.png | 乐：更明显的笑眼 |
| eye_blink_30.png | 眨眼第一帧 |

| 目录 | 星座 | 配色与角色气质 |
|---|---|---|
| scorpio | 天蝎座 | 绯红、紫红、深紫；沉静、专注、有神秘感 |
| pisces | 双鱼座 | 梦幻蓝、淡紫、少量水青；温柔、富有想象力 |
| cancer | 巨蟹座 | 月光银蓝、珍珠青；柔和、安定、有陪伴感 |

星座气质仅作为角色美术设定。配色参考现有 LED 星座主色相：天蝎 345°、双鱼 230°、巨蟹 190°，没有修改灯光代码。

## 与现有代码的关系

- 当前 C1 使用主眼、喜、怒、哀、乐和三张眨眼图，共八张；睡眠由纯黑帧承担。
- 三套 C1 PNG 文件已齐；是美术素材，尚未转成可烧录资产。眨眼闭合百分比是生成目标，不代表像素级测量值；连续播放效果仍待屏幕验收。
- 转换：`scripts/convert_s3_c1_eyes.py --src image/zodiac/scorpio --out image/zodiac/scorpio/s3_128x160 --preview`。主眼 RGBA 会先压黑底。加 `--install` 才复制到板级 `assets/`（先备份旧 bin）。
- 2026-09-20：三套均已转 40960 字节 RGB565；固件当前嵌入 **scorpio**。双鱼/巨蟹在各自 `s3_128x160/`，尚未嵌入。无运行时换皮肤。
- P4 使用 240×240 资产。高清原图需转换及真机验收后才能用于固件。
- 左眼由固件水平镜像生成，无需单独生成图片。

本轮属于视觉设计草案，不修改原有图片、固件、构建配置或部署状态。

## 原图检查

24 张实际输出均为 1254×1254 PNG，已逐张查看单眼构图、配色、眼睑方向及眨眼递进，并核对文件名、解码、尺寸和文件哈希无重复，记录见 `validation.json`。天蝎与双鱼的怒表情已重新生成修正。

三个主眼原图保持不变，含透明像素与圆外光晕；新增帧按不透明黑底要求生成。生成式编辑并非像素级锁定，部分高光、眼睑边缘存在变化。上板前仍需统一黑底与圆形边界、检查帧间对齐，缩放并转 RGB565。本轮未构建或烧录。
