## 已发现的问题与证据

1. 摄像头枚举支持 MJPEG：1280×720 默认 15fps；854×480、800×480 默认 20fps；640×480、480×320、320×240 默认 30fps。旧版固定请求 640×480@15fps 不匹配；160×120 不在本次枚举列表。
2. 存在枚举延迟、`no USB device on U4`、已枚举但打开失败等状态；软件复位不能等同摄像头断电复位，供电、USB 连接与 Host 重新枚举仍需专项检查，不能直接认定摄像头损坏。
3. 旧版控制协商超时后关闭仍有控制传输的设备，触发 `usbh_dev_close` 的 `num_ctrl_xfers_inflight == 0` 断言。第三轮延迟至完成回调关闭仍复现，addr2line 定位 `ctrl_xfer_cb`；USBH 通知回调后才扣减计数，回调不能直接释放最后一个设备引用。
4. 拍照长时间阻塞主任务会使 AFE 送入/取出失衡；直接开关 codec 又会影响共享 I2S。软件暂停还需防止音频空闲定时器关闭双工时钟。
5. 聆听中再次唤醒曾主动断开会话。改为保持连接后仍需发送 detect 事件，只有 start 不会触发唤醒应答。
